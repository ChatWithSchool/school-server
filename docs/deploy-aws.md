# פריסה ב-AWS (הצעה, לאישור ראש הצוות)

המסמך מתאר כיוון, והוא לא נבדק בחשבון AWS של הפרויקט.

**סביבות:** `dev` ו-`stage`, כל אחת על מופע EC2 נפרד (או על מופע אחד עם שתי אפליקציות ופורטים שונים בשלב ראשון), עם `mongodb` נפרד לכל סביבה.

**שרת:**

1. התקנת Docker על המופע.
2. בניית התמונה: `docker build -t school-server .`
3. הרצה: `docker run -d --restart unless-stopped -p 4000:4000 --env-file .env school-server`
4. משתני סביבה חובה בייצור: `MONGODB_URI`, `JWT_SECRET` (מחרוזת אקראית ארוכה), `CORS_ORIGIN` (כתובת הקליינט).
5. מאחורי nginx עם HTTPS, ולא חשיפה ישירה של פורט 4000.

**קליינט:** `npm run build` ושיתוף התיקייה `dist` דרך nginx או דרך S3 עם CloudFront.

**S3:** לקבצים שמועלים (למשל קבצי ייבוא וקבצי תעודות). הרשאות IAM מינימליות למופע.

**פריסה אוטומטית:** אפשר להוסיף שלב ל-GitHub Actions שמתחבר ב-SSH ל-EC2 אחרי מיזוג ל-`dev` או ל-`stage`. מפתח ה-SSH נשמר ב-GitHub Secrets.
